# Snake Game

A simple, responsive Snake game that runs in your web browser. Guide the snake to eat food, grow longer, and avoid the walls and its own body.

## Features

- Centered game board with responsive styling
- Randomly placed food and a live score
- Keyboard and touch controls
- Start and restart buttons
- Clear game-over and win messages

## Technologies used

- HTML
- CSS
- JavaScript

## How to run locally

1. Open the project folder in VS Code.
2. Open `index.html` in a web browser.

No installation or build step is required.

## Controls

- Use the **Up**, **Down**, **Left**, and **Right** arrow keys on desktop.
- On mobile, use the directional buttons below the game board.
